#  Student Search System

A responsive React-based web application that allows users to search and filter student information easily.

##  Features

-  Search students by name
-  Filter students by gender
-  Display matching student count
-  Demo student email information
-  Clear search and filters
-  Error handling
-  Loading state
-  Responsive user interface
-  REST API integration

##  Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- REST API
- MockAPI

## Project Preview

The application provides a clean and responsive interface for searching and filtering student records.
